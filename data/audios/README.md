## Condiciones de uso

- **Solo para evaluar este proyecto.** No las reutilices, redistribuyas ni las uses para entrenar modelos.
- En las notas, las personas aparecen con iniciales. Las transcripciones crudas **no** se publican.
- Los archivos no traen ubicación ni autor; solo la fecha de exportación y la duración.
- **¿Eres una de las personas entrevistadas y quieres retirar tu audio?** Abre un issue en este repositorio. Ten en cuenta que quitar un archivo no borra las copias del historial de git: en ese caso el historial se reescribe.

Los audios se transcribieron con Whisper (`scripts/transcribe_batch.py`) para escribir las notas de `docs/research/`.
